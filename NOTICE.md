- Replaced Trinkets integration with Curios API
- Added 90+ cape items with crafting recipes
- Added custom slot icon for the cape curios slot
- Added online cape texture loading (Mojang API hashes)
- Added local cape texture support
- Adapted data generation to Forge's JSON-based recipe system
